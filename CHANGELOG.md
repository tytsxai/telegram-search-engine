# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-04-02

### Added
- Telegram channel message crawler with Telethon
- Meilisearch full-text search with Chinese NLP support (jieba, pinyin, traditional-simplified)
- Redis caching layer for search results
- Telegram Bot interface for search queries
- Docker support for crawler and bot components
- CI/CD pipeline with lint, type-check, and test jobs
