# Security Policy

## Reporting a Vulnerability

To report a security vulnerability, **do not** open a public issue. Instead, email the maintainers directly with details of the vulnerability.

## What to Include

- A clear description of the vulnerability
- Steps to reproduce the issue
- Potential impact assessment
- Any suggested mitigations (optional)

## Response Time

- **Acknowledgment**: Within 48 hours of receiving your report
- **Initial assessment**: Within 5 business days
- **Fix timeline**: Depends on severity; critical issues will be prioritized immediately

You will be kept informed of progress until the issue is resolved.

## Scope

This policy covers:
- Source code in this repository
- Dependencies managed via `pyproject.toml`
- Docker configurations
- CI/CD pipelines

Out of scope: third-party services, social engineering, and denial-of-service attacks.
